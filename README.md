# Eden Cheats Manager privacy policy website

Published at https://chrisa95g.github.io/eden-cheats-manager/.

GitHub Pages uses the root of the `gh-pages` branch in the existing app repository.
This branch contains only the website; app releases use their existing branches.

Edit `privacy-policy.md` and update the matching `<main>` content in `index.html`.
Keep the copies in the app checkout's `docs/privacy-policy.md` and `docs/index.html`
in sync. Preserve the HTML page's layout and `.nojekyll` file. Pushing this branch
publishes the updated site automatically.
